# What if I sent the wrong asset or used the wrong network?

HashLiquid deposits and withdrawals support **USDT** on **BNB Smart Chain**. Sending another asset, using another network, or withdrawing to a wallet that doesn't support USDT on BNB Smart Chain can put your funds at risk.

{% hint style="danger" %}
On-chain transactions normally cannot be reversed, so recovery is not guaranteed. Act quickly, and do not send the same transfer again.
{% endhint %}

## What to do

{% stepper %}
{% step %}
**Stop sending**

Don't repeat the transfer or try again with a different amount.
{% endstep %}

{% step %}
**Find the transaction details**

Open the transaction in your wallet or in **Transaction History** on HashLiquid. Note the transaction hash or ID.
{% endstep %}

{% step %}
**Contact HashLiquid Support**

Select the headset icon on HashLiquid and share the asset, amount, network, time, and transaction hash or ID.

Full guide: [Contact HashLiquid Support](contact-hash-support.md)
{% endstep %}
{% endstepper %}

## Avoid it next time

Before you approve any deposit or withdrawal, check that the asset is **USDT**, the network is **BNB Smart Chain**, and the amount and receiving account or wallet are correct.
