# What should I do if my deposit or withdrawal is delayed or failed?

First check **Transaction History**. Do not submit the same transfer again while its status is still **Processing**.

## Deposit is still processing

1. Check your connected wallet and confirm that the transaction was submitted.
2. In HashLiquid, open the account menu and select **Transaction History**.
3. Open the deposit and check its latest status.
4. Wait for the network confirmation and HashLiquid balance update.

If the transaction is complete in your wallet but the HashLiquid balance has not updated, [contact HashLiquid Support](contact-hash-support.md). Include the wallet transaction hash or ID if it is available.

## Withdrawal is still processing

1. Open **Transaction History** and find the withdrawal.
2. Check its latest status and transaction details.
3. Check the receiving account or wallet shown in the withdrawal details for the incoming asset.
4. Wait for the status and wallet balance to update.

{% hint style="info" %}
Closing the status page does not cancel a submitted withdrawal.
{% endhint %}

## Transfer shows Failed

Check whether the amount has returned to the available balance before trying again. If it has not, or the reason for failure is unclear, [contact HashLiquid Support](contact-hash-support.md).

Provide the transfer type, asset, amount, network, time, and transaction ID if available.
