# How do I add, edit, or remove a Payment Method?

Add a Payment Method before selling crypto so the buyer knows where to send the fiat payment.

{% hint style="warning" %}
Use only a payment account in your own name. The account-holder name must match your verified identity.
{% endhint %}

## Add a Payment Method

{% stepper %}
{% step %}
**Open your account menu**

Sign in to HashLiquid and select the **account** icon.
{% endstep %}

{% step %}
Select **Payment Method**.
{% endstep %}

{% step %}
**Start adding a new method**

Select **Add a Payment Method**.



<img src="../.gitbook/assets/Image image12 (1).png" alt="payment method list" height="418" width="327">
{% endstep %}

{% step %}
**Enter your account details**

Choose a bank or payment service and enter the requested account information.



<img src="../.gitbook/assets/Image image13 (1).png" alt="Select a payment method" height="418" width="365">
{% endstep %}

{% step %}
**Save**

Review the details, then confirm to save the Payment Method.
{% endstep %}
{% endstepper %}

{% hint style="danger" %}
Never provide an online-banking password, card PIN, wallet private key, or recovery phrase when adding a Payment Method.
{% endhint %}

## Edit or remove a Payment Method

1. Open **Payment Method**.
2. Find the Payment Method you added on HashLiquid.
3. Select **Edit** to update it, or **Delete** to remove it.
4. Confirm the change.

{% hint style="warning" %}
Removing a Payment Method prevents it from being selected for new HashLiquid orders. Resolve any active order using that Payment Method before removing it.
{% endhint %}

## Why can't I use a Payment Method for an order?

The Payment Method may not support the order's fiat currency or the selected advertisement. Use one of the Payment Methods shown as available for that order.
