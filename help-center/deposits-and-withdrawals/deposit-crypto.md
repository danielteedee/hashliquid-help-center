# How do I deposit crypto to HashLiquid?

Use **Deposit** to transfer USDT from your connected wallet to your HashLiquid Account via BNB Chain.

## Deposit crypto

{% stepper %}
{% step %}
**Open Deposit**

Sign in to HashLiquid and select **Deposit**.
{% endstep %}

{% step %}
**Check the tab**

Confirm that the **Deposit** tab is selected.
{% endstep %}

{% step %}
**Check the network and asset**

Check that the network is **BNB Chain** and the asset is **USDT**.
{% endstep %}

{% step %}
**Enter the amount**

Enter the amount, or select **Max** to use the available balance shown on the page.



<img src="../.gitbook/assets/Image image14.png" alt="enter a deposit amount" width="563">
{% endstep %}

{% step %}
**Select Deposit**

Select **Deposit**.
{% endstep %}

{% step %}
**Approve in your wallet**

Review and approve the transaction in your connected wallet.

{% hint style="danger" %}
Check the asset, network, and amount before approving the wallet request. On-chain transactions normally cannot be reversed.
{% endhint %}
{% endstep %}
{% endstepper %}

## Check your deposit

After approving the transaction, allow time for the network to process it and for your HashLiquid balance to update. Do not submit the same deposit again while the first transaction is processing.

To check the latest status:

1. Open the **account** menu.
2. Select **Transaction History**.
3. Open the relevant deposit.

If the transaction is complete in your wallet but your HashLiquid balance has not updated, [contact HashLiquid Support](../troubleshooting-and-support/contact-hash-support.md). Provide the wallet transaction hash or ID if it is available.

{% hint style="warning" %}
Never share your private key or recovery phrase.
{% endhint %}
