# How do I view and manage my P2P orders?

Open **Order History** to find your Buy and Sell orders, check their status, and continue an ongoing order.

## View your P2P orders

{% stepper %}
{% step %}
**Sign in**

Sign in to HashLiquid.
{% endstep %}

{% step %}
**Open your orders**

Select the **orders** icon in the upper-right corner. You can also open the account menu and select **Transaction History**.
{% endstep %}

{% step %}
**Choose Buy or Sell**

Select **Buy** or **Sell**.
{% endstep %}

{% step %}
**Filter the list**

Use **All**, **Ongoing**, or **Dispute** to find the order you need.
{% endstep %}

{% step %}
**Open the order**

Select an order to open its details.



<img src="../.gitbook/assets/Image image23.png" alt="Active P2P Order" height="222" width="523">
{% endstep %}
{% endstepper %}

The order list shows the current status of each order, such as **Pending Payment**, **Pending Release**, **Releasing**, **Completed**, **Canceled**, or **In Dispute**.

{% hint style="info" %}
**Note:** The Deposit and Withdraw tabs contain funding transactions, not P2P orders.
{% endhint %}

## Continue an ongoing order

Open the order and follow the action shown for its current status. Depending on whether you are buying or selling, you may need to:

* Complete payment;
* Upload payment proof;
* Wait for the counterparty;
* Confirm receipt and release crypto; or
* Respond to a Dispute.

You can use the order chat to send text, images, or video when these options are available.

{% hint style="warning" %}
**Important:** If you are selling crypto, verify the payment in your own bank or payment account before releasing crypto. A screenshot or chat message alone is not proof of receipt.
{% endhint %}

## Cancel an order

If **Cancel Order** is available, select it and review the confirmation before continuing. Do not cancel an order after you have made payment. If payment has already been made or another problem occurs, use the order chat and raise a [Dispute](../troubleshooting-and-support/disputes.md) instead.

Once an order action is processing, wait for the status to update and do not submit the same action again.
